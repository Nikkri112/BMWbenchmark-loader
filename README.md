# BMWbenchmark-loader

Автоматизация запуска **Black Myth: Wukong Benchmark Tool** и получения результатов CPU/GPU-тестов.

Проект запускает бенчмарк, управляет настройками игры, делает скриншот результата и извлекает показатели FPS и VRAM с помощью OCR.

## Основные возможности

- автоматический поиск Steam и Benchmark Tool;
- сбор характеристик компьютера;
- отдельный профиль для CPU-теста;
- отдельный профиль для GPU-теста;
- автоматический запуск Benchmark Tool;
- получение скриншота результатов;
- OCR-распознавание результатов;
- извлечение среднего, максимального, минимального FPS, 5-го перцентиля и VRAM;
- восстановление исходных настроек после тестирования;
- создание текстового отчёта.

## Основные решения

### OCR

Используется встроенный Windows OCR:

`Windows.Media.Ocr.OcrEngine`

OCR вызывается через PowerShell/WinRT. Дополнительный OCR-движок вроде Tesseract не требуется.

OCR возвращает не только текст, но и координаты слов. Это позволяет использовать положение элементов интерфейса при поиске результатов.

### Обработка ошибок OCR

Обычный OCR не всегда корректно распознаёт крупные цифры интерфейса.

Например:

```text
54 FPS
```

может быть распознано как:

```text
5
4
FPS
```

Поэтому `ResultParser` объединяет соседние цифры:

```text
5 + 4 -> 54
```

Для числовых областей также используются увеличение изображения, grayscale, повышение контраста, бинаризация и несколько вариантов OCR.

VRAM обрабатывается отдельно, поэтому значения вроде `4,7 GB` не превращаются ошибочно в `47`.

## Что необходимо для запуска

- Windows 10/11;
- Steam;
- установленный Black Myth: Wukong Benchmark Tool;
- PowerShell;
- .NET Framework / C# compiler `csc.exe`;
- языковые данные Windows OCR.


## Сборка

В корне проекта:

```powershell
.\build.ps1
```

Скрипт использует стандартный C# compiler:

```text
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

или 32-битную версию:

```text
C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe
```

После сборки появляется `BMWBenchmarkLoader.exe`.

## Запуск

Полный тест CPU + GPU:

```powershell
.\BMWBenchmarkLoader.exe
```

Только CPU:

```powershell
.\BMWBenchmarkLoader.exe --cpu-only
```

Только GPU:

```powershell
.\BMWBenchmarkLoader.exe --gpu-only
```

Сохранение отчёта:

```powershell
.\BMWBenchmarkLoader.exe --out="C:\temp\benchmark.txt"
```

## Отладка OCR

Можно проверить OCR на готовом скриншоте без запуска Benchmark Tool:

```powershell
.\BMWBenchmarkLoader.exe --ocr-test="C:\screenshots\result.png"
```

В консоли выводятся сырой OCR, распознанные значения и `IsValid`.


## Временные файлы

Во время работы используется:

```text
%TEMP%\bmwbench_loader
```

Там находятся временные изображения и результаты OCR.

## Доступность OCR

Используемый OCR является компонентом Windows и работает локально.

Основное ограничение — реализация привязана к Windows.

Используются:

```text
Windows.Media.Ocr
Windows.Globalization
Windows.Graphics.Imaging
```

## Ограничения

Парсер рассчитан на экран результатов конкретного Benchmark Tool.

Если изменятся расположение элементов, масштаб интерфейса, дизайн, язык или разрешение, может потребоваться изменение `ResultParser`.

## Профили тестирования

CPU-тест ориентирован на нагрузку процессора и уменьшение влияния GPU.

GPU-тест ориентирован на максимальную нагрузку видеокарты.

После тестирования программа пытается восстановить исходные настройки.

## Результат

После обычного запуска создаётся:

```text
BMWbenchmark_report_YYYY-MM-DD_HH-mm-ss.txt
```

Отчёт содержит характеристики ПК, результаты CPU/GPU-тестов, настройки и информацию об ошибках.
